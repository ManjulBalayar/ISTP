ISTP Data Visualization Tool

The data tool allows users to explore ISTP data for each of the 99 communities. Data are displayed as charts with percentages. Users can display data for a community by year, indicator, and by demographic groupings. For questions, contact Dr. David Peters at istp@iastate.edu.

Instructions:

  • Select Topic (Quality of Life or Social Capital)
  • Select the Data Indicator
  • Select the Year (1994, 2004, or 2014. 2024 will be released soon)
  • Select the Community
  • Select the Demographic Breakout (age, sex, tenure, income, or all persons)
  • Select Visualize to generate the charts
  • Select Reset to clear all your options and start over.
